The "On-call handoff" event (id: ev_handoff) exists on Leo's on-call calendar (leo-oncall@northwind.example), owned by leo.park@northwind.example. However, the currently authenticated user (jordan.lee@northwind.example) has only "reader" access to that calendar. Attempts to modify the event's visibility to "private" via PATCH returned 403 "Insufficient permissions," and the calendar's ACL could not even be listed (403). There is no copy of the event on any calendar the user owns or has write access to, and a reader cannot be granted a higher role by themselves. Therefore the visibility cannot be changed with the current permissions — the calendar owner (Leo Park, leo.park@northwind.example) must either grant writer access or set the event to private.
