The modified date of the Finance folder cannot be set to February 10, 2026. I located the folder (ID 7100) and attempted to set its modified_at to 2026-02-10 via PUT /folders/7100 in several ways (ISO 8601, date-only, with timezone/milliseconds, combined with other field changes). In every case, the Box API reset modified_at to the current server time and ignored the value provided. In Box, modified_at (and content_modified_at) are read-only, server-managed fields that are automatically updated when the folder is modified; there is no API parameter to set a custom/past modified date. I also reverted the description I temporarily changed. Therefore, this task is not achievable through the Box API.
