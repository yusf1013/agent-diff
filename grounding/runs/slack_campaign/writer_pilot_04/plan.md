# Fresh writer and reflection comparison

Use the same ten route/mode/count assignments as writer_pilot_03. Start ten new
conversations with v4 instructions, then append one v4 self-reflection message to
each complete original response. No case-specific manual feedback or older
generated outputs enter these conversations. No compiler or solver is invoked.

Keep Sonnet 5, medium effort, 6,000 output tokens and native prefix caching unchanged.
Use two substantive calls to verify caching, then eight parallel calls per phase.
Preserve all attempts, failures, exposed thinking and native usage. Do not resample
or silently replace defective sketches. Old artifacts remain unchanged.

Compare three things:

- Fresh v4 authoring against fresh v3 authoring on the same assignments.
- The incremental effect and possible regressions of one v4 reflection turn.
- Final v4 sketches against final v3 sketches, retaining incomplete attempts in
  the denominator and distinguishing conceptual validity, construction completeness
  and challenge potential.

Manually assess sketches before seeing their reflection outputs. A ready sketch
has no material unresolved conceptual construction defect under the agreed writer
standard, including required negatives. Ordinary compilation and API validation
remain necessary. Record the evidence for each decision; self-reported checks are
not ground truth. One run per assignment measures this batch, not repeatability.

The ten assignments have informed prompt development and are not a held-out test.
Keep any future unseen-route validation separate. The v4 prompts are a combined
change, so differences cannot be attributed to an individual instruction alone.
