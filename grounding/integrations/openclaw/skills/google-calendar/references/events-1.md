# Google Calendar API: events-1

## GET /calendars/{calendarId}/events/{eventId}
Returns an event based on its Google Calendar ID. To retrieve an event using its iCalendar ID, call the events.list method using the iCalUID parameter.

**Parameters:**
  path:
    - `calendarId` (string, **required**): Calendar identifier. To retrieve calendar IDs call the calendarList.list method. If you want to access the primary calendar of the currently logged in user, use the 'primary' keyword.
    - `eventId` (string, **required**): Event identifier.
  query:
    - `alwaysIncludeEmail` (boolean, optional): Deprecated and ignored. A value will always be returned in the email field for the organizer, creator and attendees, even if no real email address is available.
    - `maxAttendees` (integer, optional): The maximum number of attendees to include in the response. If there are more than the specified number of attendees, only the participant is returned.
    - `timeZone` (string, optional): Time zone used in the response. The default is the time zone of the calendar.

## POST /calendars/{calendarId}/events
Creates an event.

**Parameters:**
  path:
    - `calendarId` (string, **required**): Calendar identifier. To retrieve calendar IDs call the calendarList.list method. If you want to access the primary calendar of the currently logged in user, use the 'primary' keyword.
  query:
    - `conferenceDataVersion` (integer, optional): Version number of conference data supported by the API client. Version 0 assumes no conference data support. Version 1 enables support for copying of ConferenceData as well as for creating new conferences. The default is 0. Acceptable values are 0 to 1, inclusive.
    - `maxAttendees` (integer, optional): The maximum number of attendees to include in the response. If there are more than the specified number of attendees, only the participant is returned.
    - `sendNotifications` (boolean, optional): Deprecated. Please use sendUpdates instead. Whether to send notifications about the creation of the new event. The default is false.
    - `sendUpdates` (string, optional): Whether to send notifications about the creation of the new event. Note that some emails might still be sent. The default is false.
    - `supportsAttachments` (boolean, optional): Whether API client performing operation supports event attachments. The default is False.
  body:
    - `start` (object, **required**): The (inclusive) start time of the event. For a recurring event, this is the start time of the first instance.
    - `end` (object, **required**): The (exclusive) end time of the event. For a recurring event, this is the end time of the first instance.
    - `summary` (string, optional): Title of the event.
    - `description` (string, optional): Description of the event. Can contain HTML.
    - `location` (string, optional): Geographic location of the event as free-form text.
    - `colorId` (string, optional): The color of the event. This is an ID referring to an entry in the event section of the colors definition.
    - `id` (string, optional): Opaque identifier of the event. If not specified, it will be automatically generated by the server. Must be between 5 and 1024 characters, using base32hex encoding (lowercase letters a-v and digits 0-9).
    - `status` (string, optional): Status of the event. Possible values: 'confirmed' (default), 'tentative', 'cancelled'.
    - `visibility` (string, optional): Visibility of the event. Possible values: 'default', 'public', 'private', 'confidential'.
    - `transparency` (string, optional): Whether the event blocks time on the calendar. Possible values: 'opaque' (busy, default), 'transparent' (available).
    - `eventType` (string, optional): Specific type of the event. Cannot be modified after creation. Possible values: 'birthday', 'default', 'focusTime', 'outOfOffice', 'workingLocation'.
    - `recurrence` (array, optional): List of RRULE, EXRULE, RDATE and EXDATE lines for a recurring event, as specified in RFC5545.
    - `attendees` (array, optional): The attendees of the event.
    - `reminders` (object, optional): Information about the event's reminders.
    - `conferenceData` (object, optional): Conference-related information, such as details of a Google Meet conference. To create new conference details use the createRequest field. Set conferenceDataVersion query parameter to 1 to persist changes.
    - `attachments` (array, optional): File attachments for the event.
    - `extendedProperties` (object, optional): Extended properties of the event.
    - `source` (object, optional): Source from which the event was created.
    - `guestsCanInviteOthers` (boolean, optional): Whether attendees other than the organizer can invite others to the event. Default is True.
    - `guestsCanModify` (boolean, optional): Whether attendees other than the organizer can modify the event. Default is False.
    - `guestsCanSeeOtherGuests` (boolean, optional): Whether attendees other than the organizer can see who the event's attendees are. Default is True.
    - `anyoneCanAddSelf` (boolean, optional): Whether anyone can invite themselves to the event (deprecated). Default is False.
    - `sequence` (integer, optional): Sequence number as per iCalendar.
    - `originalStartTime` (object, optional): For an instance of a recurring event, this is the time at which this event would start according to the recurrence data in the recurring event identified by recurringEventId.
    - `workingLocationProperties` (object, optional): Working location event data. Used if eventType is 'workingLocation'.
    - `focusTimeProperties` (object, optional): Focus Time event data. Used if eventType is 'focusTime'.
    - `outOfOfficeProperties` (object, optional): Out of office event data. Used if eventType is 'outOfOffice'.
    - `birthdayProperties` (object, optional): Birthday or special event data. Used if eventType is 'birthday'. Immutable.

## PATCH /calendars/{calendarId}/events/{eventId}
Updates an event. This method supports patch semantics. Note that each patch request consumes three quota units; prefer using a get followed by an update. The field values you specify replace the existing values. Fields that you don't specify in the request remain unchanged. Array fields, if specified, overwrite the existing arrays; this discards any previous array elements.

**Parameters:**
  path:
    - `calendarId` (string, **required**): Calendar identifier. To retrieve calendar IDs call the calendarList.list method. If you want to access the primary calendar of the currently logged in user, use the 'primary' keyword.
    - `eventId` (string, **required**): Event identifier.
  query:
    - `alwaysIncludeEmail` (boolean, optional): Deprecated and ignored. A value will always be returned in the email field for the organizer, creator and attendees, even if no real email address is available.
    - `conferenceDataVersion` (integer, optional): Version number of conference data supported by the API client. Version 0 assumes no conference data support and ignores conference data in the event's body. Version 1 enables support for copying of ConferenceData as well as for creating new conferences using the createRequest field of conferenceData. The default is 0. Acceptable values are 0 to 1, inclusive.
    - `maxAttendees` (integer, optional): The maximum number of attendees to include in the response. If there are more than the specified number of attendees, only the participant is returned.
    - `sendNotifications` (boolean, optional): Deprecated. Please use sendUpdates instead. Whether to send notifications about the event update. The default is false.
    - `sendUpdates` (string, optional): Guests who should receive notifications about the event update (for example, title changes, etc.).
    - `supportsAttachments` (boolean, optional): Whether API client performing operation supports event attachments. The default is False.
  body:
    - `summary` (string, optional): Title of the event.
    - `description` (string, optional): Description of the event. Can contain HTML.
    - `location` (string, optional): Geographic location of the event as free-form text.
    - `start` (object, optional): The (inclusive) start time of the event.
    - `end` (object, optional): The (exclusive) end time of the event.
    - `attendees` (array, optional): The attendees of the event.
    - `recurrence` (array, optional): List of RRULE, EXRULE, RDATE and EXDATE lines for a recurring event, as specified in RFC5545.
    - `colorId` (string, optional): The color of the event. This is an ID referring to an entry in the event section of the colors definition.
    - `reminders` (object, optional): Information about the event's reminders.
    - `status` (string, optional): Status of the event: 'confirmed', 'tentative', or 'cancelled'.
    - `visibility` (string, optional): Visibility of the event: 'default', 'public', 'private', or 'confidential'.
    - `transparency` (string, optional): Whether the event blocks time on the calendar: 'opaque' (busy) or 'transparent' (available).
