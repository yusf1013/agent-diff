## Decision rule

A source-derived answer can be fully checked through its requested facts or scalar value. Requiring source IDs, evidence that records were read, or intermediate calculation steps would exceed this outcome-only standard. A transformation can likewise encode the correct referent through a derived output handle: Robert’s question belongs to a thread, and a reply uses that thread’s parent timestamp.

The actual predicate still matters. A topic word need not establish a summary; a number somewhere in a string need not be the reported count; a person’s name somewhere in a report need not identify them as a reply author. Retained partial labels now state a concrete final-content or final-state gap. An aggregate output does not need to expose the underlying individual records if it completely checks the requested aggregate facts.

This does not certify full task correctness, arbitrary-language consistency, every formatting detail, or delivery links handled by other obligations. It assesses the grounded contribution at the existing card boundary. No label is lowered merely because a matcher uses final outputs, tolerates extra formatting, or cannot distinguish correct results obtained from different sources.
