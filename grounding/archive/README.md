# Superseded workflows

[slack_campaign/](slack_campaign/) contains the earlier JSON-first writer/compiler campaigns, recovery scripts, mutation workflows, reporting tools and old prompt versions. It is retained for audit and reuse of specific ideas. Current conceptual writer/compiler entry points are in [generation/](../generation/README.md); shared runtime, evaluator and usage code have dedicated homes.

Archived recipes were updated for relocated Python imports and repository paths where practical, but their historical run layouts and assumptions remain. They are not a supported alternate launch path for the current experiment. Consult a script before executing it: some old scripts perform paid calls or mutate run summaries by default. Historical results remain in [runs/slack_campaign](../runs/slack_campaign/), not in this source archive.
